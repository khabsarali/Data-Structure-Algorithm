# Lab 1 — Array Input and Display

**Task:** Input an array of numbers, then display it.

Read the size, validate it, store each integer using a loop, then print each element using another loop.

**Example input:** `5 10 20 30 40 50`

**Result:** `Array: 10 20 30 40 50`

**Roman Urdu:** Pehle size lete hain. Phir loop se har number array mein rakhte hain. Doosra loop tamam numbers ko usi order mein screen par dikhata hai. Index 0 se shuru hota hai.

Time: O(n). Storage: fixed array of 100 integers, O(1) relative to input size.
