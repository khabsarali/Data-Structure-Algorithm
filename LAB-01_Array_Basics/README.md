# Array Basics

Read the size and integers, then display them in their original order.

## Example

File: `array_basic.cpp`

Input: `3 10 20 30`

Result: `Original array: 10 20 30`

Input begins with size/count followed by elements, then task-specific target/position values. Array positions start at 1. Pointer addresses vary per run.

## Compile and run

From the repository root:

```sh
g++ -std=c++11 -Wall -Wextra -pedantic LAB-01_Array_Basics/array_basic.cpp -o lab
./lab
```

Compile each file separately. On Windows, use `lab.exe` as output and run `./lab.exe`.

## Complexity

O(n) time; O(1) auxiliary space.

**Roman Urdu:** Pehle size aur numbers input karte hain, phir loop se unhein display karte hain.
